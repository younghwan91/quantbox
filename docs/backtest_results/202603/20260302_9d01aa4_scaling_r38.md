## 교훈 (Lessons Learned)

1. **비유동 코인은 독** — PF=0.936, EV=-6.8bp. VR squeeze는 유동성이 충분한 시장에서만 작동.
2. **ρ_concurrent = 0.051** → 동시 진행 트레이드가 거의 무상관. 슬롯 늘리기가 순수 복리 효과.
3. **3→5슬롯이 최적** — 3슬롯: 안전, 5슬롯: 공격적. 6슬롯 이후 한계수익 음수.
4. **레버리지 증가 = 청산 위험** — 1slot×5x의 DD 99.8%. 같은 수익을 5slot×1x으로 DD 72.9%에 달성 가능.
