## 결론

### 1. 현재 파라미터 (0.015, 0.015, 0.001)는 이미 최적에 근접

- PF=10.229, Calmar=14,133. 변경 불필요.
- **s_sl ≠ trail_activate 조합은 항상 열등.** "BEP 낮추기" 가설 기각.

### 2. (0.013, 0.013, 0.001)이 유일한 경쟁 대안

- Calmar +49% (21,070 vs 14,133), PF 거의 동일 (10.3 vs 10.2)
- N +8.9% (6,848 vs 6,290) — 더 많은 거래 기회
- BEP 1.56% (vs 1.76%) — 라이브 우려였던 breakeven 낮아짐
- **단, MaxDD 2.8% vs 2.6% — 거의 동일**
- **리스크:** SL 1.3%로 좁아짐 → 변동성 높을 때 조기 SL 가능성

### 3. 클리프 리스크 (r77 재확인)

- 0.015 ± 0.001 → PF 34~37% 하락 (5.6~6.4x)
- 실거래 슬리피지/지연이 0.001 (10bp) 단위의 차이를 만들 수 있음
- **모니터링 필수:** 월간 WR/PF 추적

### 4. 라이브 BEP 문제의 진짜 원인

- 파라미터 문제가 아님 — 백테스트에선 EV +54bp로 충분히 수익적
- 라이브 7건 (N=7)은 통계적으로 무의미 (분산 지배 구간)
- **처방:** 파라미터 변경 대신 N 축적 대기
