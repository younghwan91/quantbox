## 핵심 발견

### 1. Cliff Edge 확인 — act=0.015는 극도로 날카로운 peak

```
act=0.012 → PF=4.16 (dist=0.001)
act=0.015 → PF=10.23 (dist=0.001)  ← +146% jump
act=0.018 → PF=3.07 (dist=0.001)   ← -70% cliff
```

act=0.015에서 양방향 모두 가파른 절벽. r77의 "±0.003 → PF -60~75%"  정확히 재현.  
→ **이 파라미터는 시장 구조에 민감하게 최적화되어 있다.**  
→ 라이브 모니터링 필수. WR이 2주 연속 <55%이면 즉시 점검.

### 2. `(0.015, 0.0005)` — IS 최적, 하지만 더 날카로운 cliff

| | act=0.015, dist=0.001 (PROD) | act=0.015, dist=0.0005 (IS Best) |
|--|--|--|
| PF | 10.23 | **15.82** (+55%) |
| EV | +54.1bp | +59.2bp |
| MaxDD | 2.6% | **1.8%** |
| Calmar | 10,175 | **24,204** (+138%) |

`dist=0.0005`는 trail이 더 늦게 발동 (더 적은 이익 반납) → PF/Calmar 개선.  
그러나 `dist` 축도 cliff가 있는지는 더 세밀한 검증 필요.  
**IS-only 결과 → 즉시 프로덕션 적용 금지.**

### 3. `dist` 축: 작을수록 Calmar 단조 증가

dist가 작을수록 (trail이 촘촘할수록) 승리한 거래에서 이익을 덜 반납 → PF 상승.  
하지만 실거래에서는 슬리피지 + 틱 노이즈로 `dist=0.0005`는 조기 청산 위험.  
**실거래 실행 품질을 고려하면 현재 `dist=0.001`이 더 robust할 가능성.**

### 4. act=0.005의 함정 — 높은 Calmar, 높은 DD

`(0.005, 0.0005)` Calmar=23,018이지만 MaxDD=24.5%.  
실거래 DD 버퍼가 없는 상황에서 위험. **현재 계좌 DD가 이미 8.3%이므로 금지.**
