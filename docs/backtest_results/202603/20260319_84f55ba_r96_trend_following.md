→ 이는 **VR Squeeze와 동일한 구조** (압축 → 이탈 초입).

## 핵심 진단: 설계 목표 미달성

### 문제 1: avg_hold = 16h (0.7일) — 추세추종이 아님

```
목표: avg_hold 1-3주 (40-120 4h bars)
실제: avg_hold 3.9 × 4h = 15.6h = 0.65일
```

EMA(8,21) 4h에서 심볼당 연 81회 신호. 크립토의 4h 변동성이 너무 높아 EMA cross가  
거의 매일 발생 → SL(2%)이 1-2바 내 발동.

### 문제 2: ADX 역상관 → VR Squeeze와 구조적 중복

EMA 크로스 시점 ADX 분포 (수정 후):
- 평균 ADX = 21.3 (0-100 스케일)
- ADX>25: 27%, ADX>30: 14%
- **낮은 ADX(조용한 시장)에서 더 좋은 신호** ← VR 스퀴즈와 동일 원리

두 전략 모두 "조용한 구간 → 첫 방향 움직임"을 잡음. 포트폴리오 분산 효과 없음.

### 문제 3: MaxDD=95.3% (1x compound)

WR=36% + avg_hold 16h + 높은 빈도 → 연속 SL 손실 구간에서 누적 손실 심각.  
실제 10슬롯 포트폴리오 MaxDD ≈ 95% × (1 slot / 10 slots) × L/N 보정으로 낮아지지만,  
VR squeeze MaxDD=60.5% vs TF MaxDD=95.3%는 위험 신호.
