## 방법론

r54에서 밝혀진 것: 동일 TF 내 feature 필터는 포트폴리오 composition 이동 효과에 불과.

r55 신규 접근 — 신호 TF보다 작은 TF의 완성봉 활용:

- **Method A (Sub-TF VR Stackup):** 4h/1h VR 스퀴즈 시 15m VR도 압축 여부 확인
  - 룩어헤드 없음: 4h bar i 닫힐 때 15m bars [i×16 .. i×16+15] 전부 완성
- **Method B (Limit Order Pullback):** 신호 후 N봉 내 되돌림 지정가에 진입
- **Method C (MA Cluster Pullback):** 4h 브레이크아웃 후 15m 되돌림 진입

## 결론

### 효과 있는 것

**Limit Order Pullback (D_mom8, pb=0.5%, win=5):**
- PF: 1.638 → 1.694 (+3.4%)
- EV: +37 → +38bp
- N 유지율: 96.6%
- 메커니즘: 되돌림 진입 → 낮은 진입가 → SL은 그대로 → TP 비율 개선 → PF↑

### 효과 없는 것

**Sub-TF VR Stackup:** 이중 스퀴즈가 오히려 에너지 소진 신호. PF 일관 하락.  
**MA Cluster Pullback:** 브레이크아웃 직후 진입이 최적. 되돌림 대기는 불리.

1. **D_mom8 Pullback(0.5%, win=3~5)** 적용 검토 — `d_pullback_pct`, `d_pullback_window` 파라미터 추가

3. Sub-TF Stackup 중단 — r54+r55 모두 feature 기반 필터 한계 재확인
4. OOS 레짐 이동은 entry 방법과 무관한 구조적 문제 → 별도 레짐 적응 연구 필요 (r56 후보)
