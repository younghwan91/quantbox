- 거래량, 모멘텀 가속도, 종가 위치는 예측력 거의 없음

## 결론 및 권고사항

### 진짜 발견

**vr_depth가 유일한 actionable signal:**
- 승리 거래 vr_depth 평균 = 0.724, 패배 = 0.671
- `min_vr_depth` 파라미터 추가 검토 가치 있음 (0.70 임계)
- 단, 효과 크기가 작음 (Δ=0.054) — 단독으로 전략 바꿀 수준은 아님

**Entry timing 전체적 결론:**
- 현재 진입 타이밍은 이미 상당히 효율적
- 피처 기반 gate 필터는 진정한 개선이 아닌 portfolio mix 효과
- 지연 진입은 도움 안 됨

### 권고사항

| 우선순위 | 방향 | 근거 |
|---------|------|------|
| 1 | vr_depth 필터 단독 효과 검증 (r55) | 유일한 의미있는 feature |
| 2 | MA cluster 비중 증가 연구 (r55) | PF가 D_mom8보다 높음 — portfolio mix 개선 가능 |
| 3 | 레짐별 성과 분석 (2022 vs 2024) | OOS 약화 원인 규명 — entry 문제인지 regime 문제인지 |
| 4 | Entry 연구 중단 | feature들의 예측력이 너무 약해 개선 여지 미미 |
