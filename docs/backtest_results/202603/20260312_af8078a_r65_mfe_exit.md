## 근본 원인: Trail Bar-Close Execution Gap

| 구분 | 백테스트 (`sim_directional_trailing`) | 라이브 (`strategy.update_position()`) |
|------|--------------------------------------|--------------------------------------|
| peak_gain 갱신 | `bar HIGH` 기준 | `current_high` 기준 (동일) |
| trail 히트 감지 | `bar LOW ≤ trail_stop_gain` | `worst_gain = (low-entry)/entry` (동일) |
| **청산 가격** | **trail_stop_gain (intrabar 가정)** | **bar CLOSE (market order)** |
| 급락 바 결과 | +trail_stop_gain (항상 양수) | close price (음수 가능) |

**15분 바 내 급락 시나리오:**
1. Bar HIGH = +4.37% → peak_gain = 4.37% → trail_stop = 4.17% 설정
2. Bar LOW = +2.0% ≤ trail_stop (4.17%) — trail 히트 감지
3. 백테스트: trail_stop_gain = 4.17%에서 청산 → **+$125**
4. 라이브: MARKET 주문 → bar CLOSE = -1.1%에서 체결 → **-$33**
5. **Gap: $158/slot** (30x leverage 적용 시)
