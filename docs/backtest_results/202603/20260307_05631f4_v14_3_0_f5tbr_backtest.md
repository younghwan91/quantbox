## CAGR / Leverage Model Notes

> ⚠️ Per custom instruction conventions — these CAGR values must be read with the leverage model in mind.

- **1x CAGR** (`compute_metrics`): Sequential per-trade equity curve with `equity *= (1+p)`. Independent of leverage. Suitable for cross-version comparison.
- **Production CAGR** (`extended_metrics`): Same curve but `equity *= (1 + p × L/N)`. VR uses L/N=2.5, MA uses L/N=1.2, combined blended at 2.06.
- These CAGR values represent the sequential per-trade compounding model (all accepted portfolio_sim trades in chronological order). Not a simultaneous multi-slot simulation.
- **Invariant edge metrics** (leverage/period independent): PF, EV_bp, WR, RR, t-stat.
