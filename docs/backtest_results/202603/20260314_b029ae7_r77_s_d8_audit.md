## 배경 — 왜 S_d8가 오랫동안 꺼져 있었나?

**기술적 원인:** Binance **Hedge Mode** 없이 straddle은 구조적으로 불가능.
- One-Way Mode: 동일 심볼에 LONG + SHORT 동시 보유 불가. SHORT 주문이 LONG 포지션을 reduce함.
- 코드에 명시: `straddle_enabled: bool = False  # Phase 2: disabled until hedge mode`
- Hedge Mode 구현 머지(commit 58ae3d9) 후 활성화됨.

**백테스팅 공백의 결과:**
- r72/r73 3전략 combined는 2026-03-13에야 처음 실행됨 (straddle 활성화 후).
- 그 이전 검증 없이 라이브 활성화 → 현재 open positions 대부분이 S_d8.

## 주요 리스크 경고

### ⚠️ 리스크 1: s_trail_activate cliff edge
현재 프로덕션 값(1.5%)이 날카로운 peak. 실거래에서 시장 구조가 바뀌어 최적 trail_activate가 이동하면 성과가 급격히 하락할 수 있음.

**권장 조치:**
1. 라이브 WR과 PF를 주기적으로 모니터링 (월 단위)
2. 실거래 trail exit 비율이 50% 미만으로 떨어지면 trail_activate 재검토
3. 향후 r78에서 trail_activate와 trail_distance 동시 2D 스윕 권장

### ⚠️ 리스크 2: 성능 하락 추세
2020-2021(PF=21+) → 2022-2025(PF=4-8). 시장이 계속 정상화되면 PF가 더 하락할 수 있음. 여전히 수익(PF=4+)이지만 과거 수치로 미래를 과대 기대하면 안 됨.

### ℹ️ IS/OOS gap (3.27x) 맥락
IS(2020-2023) PF=16.4 vs OOS(2023-2026) PF=5.0. gap이 크지만 OOS PF=5.0은 절대적으로 우수. 연도별 분석(2023=5.1, 2024=4.2, 2025=5.4)과 일치하므로 과적합이 아닌 시장 구조 변화로 해석.

## 결론 및 권장사항

**S_d8(Straddle)은 신뢰할 수 있는 전략이다.** 6년 모두 수익, MaxDD=3.5%, Bootstrap 100% P(PF≥1.0)는 수치상 이례적으로 강한 엣지를 보여준다.

1. **s_trail_activate=0.015** 이 하나의 파라미터에 전략 성패가 집중되어 있음

3. 2024년이 최저 성과(PF=4.2)였지만 여전히 수익 — 이 수준에서도 운영 가능

**구현:** 현재 라이브 운영 중 (S_d8 활성화됨). 추가 코드 변경 없음.
