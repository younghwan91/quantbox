## 핵심 발견

### 1. TF별 신호 품질: 높을수록 좋음 (단조 증가)

```
EV: 15m(+24bp) < 30m(+42bp) < 1h(+72bp) < 4h(+150bp)
PF: 4.35 → 7.93 → 16.8 → 61.0
WR: 51% → 60% → 67% → 82%
```

**해석:** 4h squeeze는 시장 구조의 더 강력한 압축 신호를 포착한다.
더 오래 지속된 squeeze (4h)일수록 break-out 후 방향성이 더 선명하다.

### 2. "4h-only가 최적인가?" → NO

4h 단독 Calmar=1,250이지만 G_4TF Calmar=10,175 (8.1배).  
이유: **슬롯 공석 비용**. 4h-only면 슬롯 5개가 대부분 비어있음 (N=1,030/6yr = 172/yr).  
15m이 53.5%의 거래를 채워 슬롯 효율을 극대화 → G_4TF CAGR=26,040% (vs 4h-only 1,148%).

### 3. 15m의 역할: volume contributor, not alpha generator

EV=+24bp (4h의 1/6)이지만 **전체 G_4TF 거래의 53.5%**를 공급.  
4h가 "최고 품질 신호"를 선택하고, 4h 공백을 15m/30m이 채우는 구조.

### 4. MaxDD는 TF가 높을수록 낮음

```
4h MaxDD=0.9%  vs  15m MaxDD=3.3%
```
고TF 신호는 더 "확신도 높은" 신호만 선택 → 손실 거래 비율 낮음.
