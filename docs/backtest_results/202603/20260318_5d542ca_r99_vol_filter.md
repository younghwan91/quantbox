## 구조적 발견

### 왜 볼륨 필터가 N%를 70% 이상 유지하지 못하는가?

1. **VR Squeeze (D_mom8)는 이미 "희귀 이벤트" 선별 전략**
   - G_4TF로 4개 TF를 합쳐도 N=2051 (6년)
   - 볼륨 2.0× expansion 조건을 추가하면 N=93으로 95% 필터링
   - 희귀 이벤트 + 희귀 볼륨 조건 = 과도한 필터링

2. **Straddle (S_d8)도 동일**
   - 방향 중립이지만 squeeze 조건으로 이미 선별됨
   - 볼륨 필터 추가 시 N이 급감

3. **볼륨 expansion이 효과적인 이유 vs 실용성 부족**
   - Vol 2.0× spike는 "기관 참여" 시그널 (r98 발견 재확인)
   - BUT 크립토에서 이런 이벤트는 매우 드물어 연 ~15회
   - 독립 전략으로는 가능하나, 기존 전략의 "필터"로는 부적합

## 결론

1. **볼륨 필터는 VR/STRD의 "추가 필터"로 부적합**
   - 이미 희귀 이벤트 전략이므로 추가 필터링 시 N 급감
   - PF 개선은 있으나 통계적 유의성 확보 불가

2. **볼륨 expansion은 독립 신호로서의 가치 있음**
   - Vol 2.0× spike: PF 2× 이상, DD 60%p 개선
   - BUT 방향/청산 로직 필요 → 별도 전략 설계 필요

3. **권장사항**
   - VR/STRD에 볼륨 필터 추가 **포기**
   - 기존 전략 유지
   - 볼륨 기반 독립 전략은 장기 연구 과제로 남김
