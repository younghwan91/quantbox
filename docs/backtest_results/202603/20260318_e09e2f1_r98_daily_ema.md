### 구조적 원인

1. **EMA crossover = 초기 방향 전환 포착** — 추세가 "이미 진행 중"이 아닌 "막 시작"하는 시점.
2. **크립토 평균회귀 속성** — EMA 크로스 후 즉시 평균회귀 → 와이드 SL(15%)도 10일 내 맞음.
3. **SL width vs MaxDD 트레이드오프** — SL 넓힐수록 avg_hold 증가 but MaxDD=99%로 수렴.
4. **60 심볼 동시 크로스** — BTC gate 있어도 상관계수 높은 심볼들이 동시에 같은 방향 크로스 → 10 슬롯 포화 → 한 방향 노출.

### Vol gate 발견 (r99 방향)

vol≥1.5× gate는 EMA crossover와 전혀 다른 신호를 선별:
- N=63 (전체의 20%), PF=1.795, DD=61.5% — 추세추종과 무관한 신호 품질
- 이 신호 = "일일 거래량이 평균의 1.5배 이상인 날의 EMA 크로스" = **고량 브레이크아웃**
- avg_hold=2.3d → 빠른 결정 (단기 모멘텀, not 추세추종)
