완전 일치.

### 1.3 레버리지 누락 (실제 버그였다)

`portfolio_sim`이 손익을 `pnl / max_concurrent`로 자기자본 비율에 환산했다.
**레버리지가 빠져 있었다.**

- 라이브: `leverage = risk_per_trade × max_concurrent / sl` → SL 1회 = 잔고의 **6%**
- 백테스트 모델: SL 1회 = 자기자본의 **0.2%**
- **30배 차이**

그래서 일손실 차단기(한도 12%)가 실데이터에서 **한 건도 막지 못했다** — 닿을 수 없는
단위로 비교하고 있었다.

수정 후:
- `portfolio_sim(daily_loss=True)`는 `sl_pct` 필수. 없으면 `ValueError`로 멈춘다.
  조용히 틀린 단위로 도는 것보다 낫다.
- 일손실 차단을 라이브처럼 **sticky**하게 바꿨다 (한 번 걸리면 자정까지, 이익이
  실현돼도 안 풀림 — `scalper.py`의 `_daily_loss_blocked`).
- 실데이터 영향: 1,652 → 1,648, 필터 전체 1,269 → 1,267.

**라이브 사이징 기준 maxDD = 50.0%다.** 보고서의 2.0%는 `portfolio_size=10` 환산값이라
라이브와 비교할 수 없다. → 열린 항목 2.3

## 3. 알아야 할 제약

### 3.1 exit은 묶을 수 없다

라이브 청산은 **Binance 서버측 브래킷 주문**(`TRAILING_STOP_MARKET`)이 한다.
백테스트는 봉 데이터로 근사한다. **공유할 코드가 존재하지 않는다.**
이 축만은 논증과 테스트로 유지할 수밖에 없다 — 사본이라서가 아니라 원리상 그렇다.

### 3.2 두 sim 계약을 혼동하지 말 것

| 함수 | 계약 |
|---|---|
| `run_ma_cluster` | 기존 백테스트 숫자와 **bit-parity**. CW는 opt-in |
| `run_ma_cluster_live` | **라이브 재현**. CW 기본 ON |
| `run_ma_cluster_live_fine_exits` | 위와 같되 청산 격자를 `exit_ratio`로 지정 (미머지) |

`run_ma_cluster`는 모놀리식 재현이라 라이브의 **2.32배** 거래를 낸다. 라이브 기대치를
논할 때 이걸 쓰면 안 된다.

### 3.3 메모리를 믿지 말 것

이 세션에서 메모리 파일 두 건이 실제와 달랐다:
- Phase 3 "미착수" → 실제로는 커밋 완료
- MA Cluster 레버리지 "5x" → 실제 계산값 **30x** (`risk 0.06 × 10 / sl 0.02`, 상한 30)

**항상 코드/커밋으로 실측할 것.**

## 4. 작업 규칙 (이 저장소 고유)

- **Top Rule: 숫자와 사실을 추측하지 말 것.** 모르면 모른다고 하고, 항상 코드/config를
  먼저 읽는다.
- 파라미터는 전부 `VolStraddleConfig()`에서 읽는다. 하드코딩 금지 (Rule #6).
  `.env`가 `settings.py` 기본값을 덮으므로 둘 다 확인.
- 백테스트는 **실제 Binance 데이터만**. `np.random` 합성 데이터 금지.
- 재구현 금지. `scripts/check_research_reimpl.py`가 pre-commit에서 막는다.
  정당한 예외는 `# harness-exempt: <이유>` 주석으로 이유를 남긴다.
- 신호/청산/비용/사이징 로직 변경은 **High 위험** — 사용자 확인 + 파리티 검증 필요.
- API 경로 변경은 **실주문 검증 필수** (2.2 참조).
- `tests/conftest.py:68`이 `VS_RISK_PER_TRADE=0.01`을 주입한다. 테스트에서
  `VolStraddleConfig()`는 **프로덕션 사이징이 아니다.** 선언 기본값이 필요하면
  `model_fields[...]`로 직접 읽을 것 (`tests/test_dust_threshold.py` 참고).

파리티 bit-parity 확인은 리팩터링 전후로 아래를 캡처해 비교하는 방식이다:

```python
from quantbox.backtest.sim_core import run_ma_cluster_live
from quantbox.backtest.trade_sim import portfolio_sim
from quantbox.research.harness import MarketData
from quantbox.strategy.vol_straddle.config import VolStraddleConfig

cfg = VolStraddleConfig()
md = MarketData.load(cfg.symbol_whitelist)
trades, dirs = run_ma_cluster_live(md.data, return_directions=True)
pnl = portfolio_sim(
    trades, cfg.max_concurrent, directions=dirs,
    btc_close=md.data["BTCUSDT"]["close"],
    dir_diversity=True, btc_gate=True, daily_loss=True,
    sl_pct=cfg.ma_cluster_sl,
)
# 기준: trades 1652건, 필터 전체 적용 후 1267건
```
