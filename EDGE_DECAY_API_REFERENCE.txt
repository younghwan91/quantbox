┌─ 2. TRADE_SIM.PY ─────────────────────────────────────────────────────────────┐
│ FUNCTION A: collect_trades_trailing()                                          │
│ ├─ Signature: (cfg, data_15m, data_1h, data_4h, "D_mom8"|"S_d8", ...)         │
│ ├─ Returns: [(sym, entry_bar_15m, exit_bar_15m, pnl_fraction), ...]           │
│ ├─ Inputs:  cfg=VolStraddleConfig object (NOT dict)                           │
│ ├─ Options: tf_group=[G_3TF|G_4TF], tf_priority=True/False, data_30m=dict     │
│ └─ Phase 1: G_3TF (15m/1h/4h), Phase 2: G_4TF (15m/30m/1h/4h) + priority      │
│                                                                                 │
│ FUNCTION B: sim_directional_trailing()                                         │
│ ├─ Returns: (pnl_array, entry_bars_array, exit_bars_array)                    │
│ ├─ PnL as fraction (0.0187 = +1.87%, -0.0100 = -1%)                           │
│ ├─ Exit order: SL → TRAIL → TP → MAXHOLD                                      │
│ └─ Params: trail_activate (when to start trailing), trail_distance             │
│                                                                                 │
│ FUNCTION C: sim_straddle_trailing()                                            │
│ ├─ Returns: (pnl_array, entry_bars, exit_bars)                                │
│ ├─ Each entry opens LONG + SHORT simultaneously                               │
│ ├─ Net PnL = leg1 + leg2 - cost                                               │
│ └─ Each leg has independent SL/TP/trailing                                    │
│                                                                                 │
│ FUNCTION D: portfolio_sim()                                                    │
│ ├─ Input: [(sym, entry_bar, exit_bar, pnl), ...]                             │
│ ├─ Output: 1-D array of accepted PnLs (chronological order)                   │
│ ├─ Filters: no overlaps same symbol, max concurrent slots, 2 slots/straddle   │
│ └─ Straddle symbols passed as frozenset for proper slot accounting            │
│                                                                                 │
│ FUNCTION E: compute_metrics()                                                  │
│ ├─ Input: pnl_array, data_years                                               │
│ ├─ Output: Dict with 14 keys: N, PF, EV_bp, t, WR, RR, avg_win/loss,         │
│ │         ret_pct, max_dd_pct, tpd, ann_ret_pct, calmar                       │
│ ├─ Uses compound equity model: equity *= (1 + pnl_per_trade)                  │
│ └─ Interpretation: PF ≥ 1.5 (good), WR 40-50%, Calmar ≥ 0.5 (strong)         │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─ 3. SIGNALS.PY ───────────────────────────────────────────────────────────────┐
│ FUNCTION A: compute_vr()                                                       │
│ ├─ Formula: VR = ATR(short, 8) / ATR(long, 56)                                │
│ ├─ Returns: array [NaN×56, then 0.68, 0.61, 0.48, ...]                        │
│ ├─ Stored key: data_15m["BTCUSDT"]["vr_8_56"]  (format: "vr_sp_lp")           │
│ ├─ Interpretation: < 0.50 = entry signal (D_mom8)                             │
│ │                  < 0.57 + duration ≥ 3 = straddle setup (S_d8)              │
│ └─ Scale-invariant: same VR periods work across all timeframes                │
│                                                                                 │
│ FUNCTION B: compute_momentum()                                                 │
│ ├─ Formula: close[i] / close[i-8] - 1                                         │
│ ├─ Returns: array of momentum fractions (e.g., 0.015 = +1.5%)                 │
│ └─ Used for direction assignment: > 0.0001 = LONG, < -0.0001 = SHORT          │
│                                                                                 │
│ FOR EDGE DECAY STUDY:                                                          │
│ • Rolling percentile: np.nanpercentile(vr[i-252:i], 20)                       │
│ • Interpretation: if 20th %ile increases → compression less rare → edge decay  │
└─────────────────────────────────────────────────────────────────────────────────┘

│ 5. PER-TRADE METADATA: collect_trades() returns ONLY (sym, e, x, pnl)        │

│    → Currently NOT provided in public API                                      │
